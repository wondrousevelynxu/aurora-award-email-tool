# 教师节海报生成器 2026

这是 2026 年教师节长图海报的独立生成器。它沿用了参考包的本地处理方式，但今年的视觉改为蓝紫、冰白与淡紫，头图使用“完整开本与背面机器人剪影”的主题构图，不复用去年的浅青色打开书本海报排版。

## 使用

1. 双击 `启动教师节生成器.command`，或在此目录运行 `python3 -m http.server 8787`。
2. 浏览器访问 `http://127.0.0.1:8787/`。
3. 默认提供 2026 示例名单和姓名占位卡片，不附带任何人物照片。可上传 Excel、头像文件夹和头图替换；头图在编辑区选择后会立即更新预览并用于导出。
4. 照片加载后保持原始比例铺满正方形卡片，不拉伸；点击任意照片卡片可手动拖动位置，使用“适应大小”、放大、缩小三个圆形按钮，或滚轮缩放。原始照片文件不会被修改，卡片边界外的部分仅在显示层隐藏。切换中文 / English 检查两版内容；中文版只显示中文，英文版只显示英文，海报文字可以直接点击编辑。
5. 点击“下载 PNG 长图”导出固定 1080px 宽的无损 PNG。

## Excel 字段

`基本信息` 表：年份、日期、中文引文、English introduction、中文结尾、English closing、中文落款。

`引路人名单` 表：中文姓名、英文姓名、中文部门、英文部门、头像文件名。

头像文件名可以与 Excel 完全一致，也可以直接使用姓名命名。上传头像文件夹后，工具会按姓名或文件名前的序号自动匹配；名单卡片以照片铺满卡片，姓名与部门显示在底部渐变遮罩上，所有照片统一平铺展示，不再按部门分组。

## 固定尺寸

海报画布固定为 1080px 宽。头部固定为 1080 × 860px；以后更换头图时建议准备同样尺寸的 PNG 或 JPG，生成器会按固定区域裁切显示，后续内容模块不会发生位移。头部左上角使用项目内置的白色渐变 Logo。字体使用项目内置的阿里妈妈普惠体无衬线字体（Regular / ExtraBold），字号按 1080px 设计基准固定；小屏设备只缩放或横向滚动预览，导出尺寸和文字比例保持不变。
